# Amazon Best Sellers 跨境选品采集工具

一个基于 Python + Selenium 的 Amazon 畅销商品采集工具。

可从 Amazon Best Sellers 榜单中获取商品名称、价格、卖家名称及卖家所在国家，方便跨境电商从业者、选品人员或研究者快速了解不同类目的热门商品及卖家分布。

## 功能

- 获取 Amazon Best Sellers 畅销商品
- 获取商品标题
- 获取商品价格
- 获取卖家名称
- 获取卖家所在国家
- 识别 Amazon 自营商品
- 支持多个商品类目
- 支持指定一个或多个类目运行
- 自动保存采集结果到 CSV
- 自动缓存已经识别过的卖家国家，减少重复查询
- 自动对 CSV 中的重复商品进行去重
- 支持 `Ctrl + C` 中断，并保存已经采集的数据

## 支持类目

目前支持：

- 厨房餐厅
- 家居厨房
- 玩具游戏
- 汽配用品
- 手机配件
- 手工制品
- 美术手工

程序默认抓取每个类目的前两页榜单数据，并尝试加载每页商品。实际获取数量可能会受到 Amazon 页面结构、网络情况以及商品状态等因素影响。

## 环境要求

- Python
- Google Chrome

安装 Python 依赖：

```bash
pip install -r requirements.txt
```

程序使用 Selenium 控制 Chrome 浏览器，并通过 `webdriver-manager` 管理 ChromeDriver。

## 使用方法

### 抓取全部类目

直接运行：

```bash
python amazon.py
```

如果不指定类目，程序会依次抓取当前配置中的全部类目。

### 抓取指定类目

例如只抓取“厨房餐厅”：

```bash
python amazon.py 厨房餐厅
```

同时抓取多个类目：

```bash
python amazon.py 厨房餐厅 玩具游戏 手机配件
```

类目名称需要与程序支持的类目名称一致。

## 输出数据

采集结果会保存到：

```text
amazon.csv
```

CSV 包含以下字段：

| 字段 | 说明 |
| --- | --- |
| 类目名 | 商品所属 Best Sellers 类目 |
| 商品标题 | Amazon 商品标题 |
| 价格 | 当前页面显示的商品价格 |
| 卖家名称 | 当前商品卖家 |
| 卖家国家 | 根据卖家公开信息提取的所在国家 |

示例：

```text
类目名,商品标题,价格,卖家名称,卖家国家
厨房餐厅,Example Product,$19.99,Example Seller,US
玩具游戏,Example Toy,$12.99,Amazon,
```

Amazon 自营商品会标记为 `Amazon`，卖家国家可能为空。

## 卖家国家缓存

程序会将已经获取到的卖家国家信息保存到：

```text
seller_country_cache.json
```

再次遇到相同卖家时，会优先读取本地缓存，减少重复访问卖家信息页面。

该文件属于程序运行过程中生成的缓存文件，默认不建议提交到 Git 仓库。

## 数据文件

以下文件属于运行过程中自动生成的数据，建议保留在本地：

```text
amazon.csv
seller_country_cache.json
```

可以在 `.gitignore` 中忽略这些文件，避免将实际采集数据和缓存提交到仓库。

## 注意事项

Amazon 的网页结构可能随时发生变化。

如果 Amazon 调整 Best Sellers 页面、商品详情页或卖家信息页的 HTML 结构，部分数据提取功能可能失效，需要更新对应的 Selenium 定位规则。

网络速度、地区、商品状态以及 Amazon 页面加载情况，也可能影响最终采集数量。

请合理控制使用频率，不建议进行高频、大规模访问。
